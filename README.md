# SQL gruplama raporları

**Gün 25 · SQL günlük çalışma**

SQL Server üzerinde küçük müşteri, ürün ve sipariş tablolarıyla sorgu alıştırması.

## Kullanım

1. Boş bir eğitim veritabanında `setup.sql` dosyasını bir kez çalıştırın.
2. `queries.sql` dosyasındaki sorguları sırayla çalıştırın.

`setup.sql` tabloları oluşturur ve örnek veri ekler; aynı veritabanında ikinci kez çalıştırmak için önce tabloları kaldırmanız gerekir.
